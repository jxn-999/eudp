Mobile-UX-Patterns die das „App-Feel" geben

  • Bottom-Tab-Navigation auf Mobile (Daumen-Reichweite). Vier Tabs: Home, Speisekarte, Warenkorb (mit Badge), Info.
  • Sticky-Cart-Bar unten auf der Speisekarte: „🛒 3 Items · 24,50 € →" — immer in Daumen-Reichweite.
  • Bottom-Sheet für Item-Detail statt Routen-Wechsel: schnelles ⤓-Wischen zum Schließen, Hintergrund bleibt.
  • Stepper-Checkout mit klarem Fortschritt (Lieferung → Adresse → Zahlung), Zurück-Button immer da.
  • Skeleton-Loader statt Spinner: Inhalt fühlt sich „schon da" an, auch auf 4G.
  • Optimistic UI: „+" tippen → Item ist sofort im Cart (kein Server-Roundtrip).
  • PWA-Install-Prompt nach 2. Besuch: „App installieren?" → Icon auf Home-Screen, Vollbild ohne Browser-Chrome.
  • Haptic Feedback bei wichtigen Aktionen (kurzes Vibrieren bei „in Cart" — wenn Browser unterstützt).
  • Desktop-Layout: gleiche Struktur, aber Karte als Grid (3 Spalten), Cart als rechte Sidebar (immer sichtbar).
